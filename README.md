## 这本书讲什么

它不是成功学手册，也不是焦虑贩卖机。全书 9 章 + 6 份附录，回答一个问题：

> 一个不想研究技术的普通人，怎么在 AI 时代过得从容一点？

| 章节 | 内容 |
|------|------|
| 序 | 「AI 搭子」时代：跳读地图，不想从头看直接对号入座 |
| 01 心态篇 | 先松绑，再出发——焦虑是这个时代的新型感冒 |
| 02 技能篇 | 你的新「超能力」——会聊天就能用好 AI |
| 03 工作与副业篇 | 上班愉快，下班搞钱——优雅高效，多一条路 |
| 04 避坑篇 | AI 挖的坑——幻觉、隐私、翻车急救 |
| 05 生活篇 | 把日子过成诗——做饭、社交、带娃让 AI 打辅助 |
| 06 注意力篇 | 保护你的注意力——最稀缺的不是信息，是不被打扰 |
| 07 成长篇 | 成为更好的自己——AI 越厉害，「人味」越值钱 |
| 08 关系篇 | AI 再懂你，也不如一个真人 |
| 终 | AI 很厉害，但你更可爱——写给五年后的自己 |

**附录（口袋工具书）**：AI 工具速查表 · 高频场景提示词模板（8 个，复制就能用）· AI 黑话小词典 · 明天就能做的 5 件小事 · AI 翻车笑话合集 · 读者共创页

每章固定栏目：🎬 场景短剧 → 💡 认知升级 → 📋 实操小清单 → 🤡 AI 翻车现场 → ✨ 今日摸鱼 KPI。不用按顺序读，翻到哪页算哪页。
